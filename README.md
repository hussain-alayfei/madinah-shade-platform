# ظل المدينة — Madinah Shade Platform

منصة ملاحة حضرية للمشاة تقترح المسار الأنسب للمشي حسب الراحة، وليس المسافة فقط. تعتمد تجربة المنتج على عوامل مثل الظل، الإجهاد الحراري، الازدحام، الإتاحة، جودة المسار، المياه والاستراحات والخدمات.

## ما الذي يحتويه هذا الـMVP؟

### تجربة المشاة
- تخطيط الرحلة من نقطة البداية إلى الوجهة.
- اختيار وقت الانطلاق.
- مقارنة أربعة أنماط للمسار: الأريح، المتوازن، الأسرع، والأثرى.
- مراجعة تفاصيل المسار قبل الانطلاق.
- خريطة تفاعلية مبنية على OpenStreetMap + Leaflet.
- تجربة ملاحة حية تجريبية مع تنبيهات وحالة الرحلة.
- ملخص الوصول وتقييم الرحلة.
- إرسال ملاحظات ميدانية.
- التحقق المجتمعي من الملاحظات.

### واجهة صانع القرار
- خريطة للنقاط ذات الأولوية.
- مؤشرات للراحة والبلاغات والمشاركة.
- قائمة أولويات التدخل.
- مؤشرات تشغيلية مرتبطة بقياس الأثر.

## المسارات

- `/` — بدء الرحلة.
- `/plan` — مقارنة المسارات.
- `/route?route=comfortable` — مراجعة المسار.
- `/navigate?route=comfortable` — الملاحة التجريبية.
- `/arrival?route=comfortable` — ملخص الرحلة والتقييم.
- `/report` — إرسال ملاحظة.
- `/community` — التحقق المجتمعي.
- `/city` — لوحة المدينة.

## التقنية

- Next.js App Router
- TypeScript
- React 19
- Leaflet + React Leaflet
- Lucide icons
- CSS design system مخصص للمشروع

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

للتأكد من TypeScript:

```bash
npm run typecheck
```

ولبناء نسخة الإنتاج:

```bash
npm run build
```

## ملاحظة مهمة عن البيانات

بيانات المسارات، درجات الراحة، الازدحام والخدمات المستخدمة حاليًا بيانات تجريبية لعرض تجربة المنتج فقط. البنية مقصودة لتُستبدل لاحقًا بمصادر GIS والطقس والظل والكثافة والخدمات الفعلية.

## مبادئ التصميم

المشروع يتجنب النمط الشائع في الواجهات المولدة آليًا: لا توجد بطاقات زخرفية بلا وظيفة، ولا gradients للزينة، ولا glassmorphism، ولا صفحات داخلية تبدأ بـhero تسويقي. الخريطة والعمل الأساسي للمستخدم لهما الأولوية على الزينة.

راجع `docs/design-principles.md` و`docs/product-flow.md` قبل أي تعديل كبير على الواجهة.
